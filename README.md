Movie Management System

This is a movie management app I built using C# and Windows Forms. You can add and delete movies, enter details like IMDb ratings and actors, and browse the web using the app’s built-in browser.

I also added a simple login screen. Only predefined users can log in with the correct username and password. Instead of using a user list or a database, I checked each account directly with `if-else` statements.

I made this project to practice Windows Forms and work with basic C# logic.
